# joshuachp Tap

## How do I install these formulae?

`brew install joshuachp/tap/<formula>`

Or `brew tap joshuachp/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "joshuachp/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
